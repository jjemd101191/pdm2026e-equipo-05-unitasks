# Evidencia de las sesiones de usuarios

Estas hojas se llenan **solo después de una sesión real**. No inventar personas, fechas, citas ni resultados.

- `U01.md`, `U02.md` y `U03.md`: una hoja por persona.
- No incluir nombres reales, datos personales, imágenes ni audios en el repositorio. Usar un alias.
- Si hay audio o foto, guardarlo fuera del repositorio y anotar «disponible con consentimiento».
- Al terminar, copiar el resumen a [`docs/usuarios.md`](../usuarios.md) y enlazar el PR de la mejora.
- Si una sesión no tuvo fallos, registrar igual lo que intentó y el resultado.
- Si un dato no se registró, escribir «no registrado». No completarlo por suposición.

El docente revisa esta hoja, la tabla de `usuarios.md` y el PR; la app no guarda un historial de sesiones y no lo necesita.
